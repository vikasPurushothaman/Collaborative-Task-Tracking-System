# Task Tracking & Team Collaboration System

## Project Overview

The **Task Tracking & Team Collaboration System** is a full-stack enterprise application designed to streamline project management, task organization, and team collaboration. It provides a centralized platform where teams can create projects, assign tasks, monitor progress, collaborate through comments and file attachments, and track productivity using real-time dashboards and analytics.

The application consists of two major components:

### Frontend

The frontend is built using **React 18**, **Vite**, **Tailwind CSS**, **Redux Toolkit**, and **TanStack Query**, delivering a modern, responsive, and intuitive user experience. It includes interactive dashboards, Kanban boards, calendar views, project and team management, AI-assisted task creation, analytics, and comprehensive authentication workflows.

### Backend

The backend is developed with **Java 21** and **Spring Boot 3**, providing a secure, scalable, and modular REST API. It implements JWT-based authentication, role-based access control (RBAC), project and task management, real-time notifications using WebSocket, AI integration for task generation and summarization, file attachment management, and comprehensive API documentation through Swagger/OpenAPI.

## Key Highlights

* Secure JWT Authentication & Role-Based Authorization
* Project, Team, and Task Management
* Kanban, List, and Calendar Task Views
* Real-Time Notifications with WebSocket
* AI-Powered Task Description & Summary Generation
* File Attachments and Comment System
* Analytics Dashboard with Interactive Charts
* RESTful API Architecture
* Responsive User Interface
* Clean, Modular, and Scalable Architecture
* Production-Ready Full-Stack Design

The system follows modern software engineering practices, including layered architecture, reusable components, service-oriented design, and clear separation between the frontend and backend. This architecture enables independent development, testing, and deployment while ensuring maintainability, scalability, and ease of future enhancements.

The project serves as a comprehensive solution for organizations, development teams, educational institutions, and businesses looking to efficiently manage projects, coordinate teams, and improve productivity through a modern collaboration platform.
